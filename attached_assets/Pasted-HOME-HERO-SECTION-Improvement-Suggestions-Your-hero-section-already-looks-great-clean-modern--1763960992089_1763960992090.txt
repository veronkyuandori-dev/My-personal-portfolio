HOME / HERO SECTION – Improvement Suggestions

Your hero section already looks great—clean, modern, with a unique color gradient. But here are some tweaks to make it look more professional and balanced:

1. Profile Photo
✔ What’s good:

Centered placement

Circular framing

🔧 Improve:

Add a soft neon glow around the profile image to match the theme.

Increase size by ~10–12% for better visual emphasis.

Add a subtle drop shadow to separate it from the busy background.

2. Name Typography
✔ What’s good:

Stylish futuristic font

Strong visual presence

🔧 Improve:

The name is slightly too large and overwhelms the section.
Reduce size by about 8–10%.

Add a slight weight increase or shadow for improved readability against the gradient.

3. Subheading (Affiliations and Memberships)
✔ Good content
🔧 Improve:

Add slightly more spacing (margin-top) after your name.

Reduce opacity of the text color to something like rgba(255,255,255,0.8) so it blends smoothly.

Make each affiliation multiline with bullet separators instead of using dots.

Example Layout:

Junior Mechatronics and Robotics Society of the Philippines (JMRSP – PnC Student Chapter)  
Member — A.Y. 2025–2026  
AWS Educate Member  
GitHub Student Developer


Looks more organized and readable.

4. Bio Text Paragraph
✔ Good content; concise.
🔧 Improve:

Increase line-height slightly to improve readability.

Consider reducing width of the text block so it does not stretch too wide.

Raise opacity a bit—currently it fades too much into the background.

5. Background Effects
✔ Nice cyber aesthetic
🔧 Improve:

Add a light radial gradient overlay behind the profile photo and name for stronger visual anchoring.

Slightly tone down background brightness (especially upper area) for contrast.

6. CTAs (Buttons)

I don’t see them in the screenshot yet, but:

Use pill-shaped buttons for a modern look.

Include icons (e.g., mail, GitHub, LinkedIn).

Add hover effects with neon glow.

🏅 CERTIFICATIONS SECTION – Improvement Suggestions

Your certifications area is very strong already, but here are enhancements to make it look more polished:

1. Card Layout
✔ Nice card structure and information hierarchy.
🔧 Improve:

The images appear cropped—give them uniform aspect ratios (e.g., 16:9 or 4:3).

Add slight rounded corners to certificate images to match the theme.

Increase spacing between cards for better breathing room.

2. Card Shadows

Add soft glow shadows around each card to create depth.

Use a subtle purple neon hue to match the portfolio aesthetic.

3. Card Footer Area

The lower part of each card (title, date, issuer) is good, but:

🔧 Improve:

Add a divider line between the image and text.

Add small icons next to:

Title (already present, good)

Issuer (e.g., AWS logo, Cisco logo, Microsoft logo — if allowed within design)

4. Text Improvements

Make the date badge slightly smaller and more compact.

Decrease line count for descriptions where possible.

Make the issuer text slightly brighter.

5. Spacing & Responsiveness

Your cards look great in desktop view, but ensure:

1 column on mobile

2 columns on tablet

3 columns on desktop (currently shown)

Spacing should adapt automatically with consistent margins.
